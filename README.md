🚀 Nome do Projeto: Super Calculadora Web

## Descrição
Este projeto é uma calculadora web simples e responsiva, desenvolvida em HTML, CSS e JavaScript puro. Seu objetivo é servir como uma demonstração de habilidades básicas de desenvolvimento Front-end e manipulação do DOM.

## ⚙️ Tecnologias Utilizadas

* **HTML5:** Estrutura básica da aplicação.
* **CSS3:** Estilização e layout responsivo.
* **JavaScript (ES6):** Lógica da calculadora (adição, subtração, multiplicação, divisão).
* **Git & GitHub:** Controle de versão e hospedagem.

## 🔧 Instalação e Uso

Você não precisa instalar nada! Como é uma aplicação puramente Front-end, basta clonar o repositório e abrir o arquivo `index.html` no seu navegador.

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/seu-usuario/super-calculadora-web.git](https://github.com/seu-usuario/super-calculadora-web.git)
    ```

2.  **Entre na pasta do projeto:**
    ```bash
    cd super-calculadora-web
    ```

3.  **Abra o arquivo:**
    Abra o arquivo `index.html` diretamente no seu navegador.

## 💻 Como Contribuir

Ficarei feliz em receber contribuições! Se você encontrou um bug ou tem uma sugestão de melhoria, siga os passos abaixo:

1.  Faça um **Fork** do projeto.
2.  Crie uma nova branch para sua funcionalidade: `git checkout -b feature/minha-melhoria`
3.  Faça o **commit** de suas alterações: `git commit -m 'feat: Adiciona função de potência'`
4.  Envie para a branch original: `git push origin feature/minha-melhoria`
5.  Abra um **Pull Request** detalhando sua alteração.

> ⚠️ **Nota:** Certifique-se de que todos os testes estejam passando antes de abrir o Pull Request.
